## A0.1 收尾：闭合最后的函数级 1:1 偏差（本会话后半）
A0.1 = 0.1.0 全部函数在权威黄金向量下 1:1 通过 `cargo test`（Overlap/Momentum/Volatility/
Volume/PriceTransform/Stat + Cycle）。此前全量 `cargo test` 从未跑过（仅跑 momentum/stat 子集），
故埋藏了三处预存在偏差，本会话全部修正：

1. **`beta`（Stat）**：原实现用原始价格 `cov/var`，但 TA-Lib `TA_BETA` 基于相邻价格**收益率**
   做线性回归（斜率 = (n·Sxy−Sx·Sy)/(n·Sxx−Sx²)，lookback = period）。逐字移植 `ta_BETA.c`
   流式算法（含 `TA_IS_ZERO` epsilon 判定与 trailing 游标预增）。同步修正 `beta_of_scaled_series`
   单测（成严格比例序列的 beta 应为 1.0，非 3.0）。
2. **`trange`/`atr`/`natr`（Volatility）**：`true_range` 原在索引 0 输出 `high[0]-low[0]`，但
   TA-Lib `TA_TRANGE[0]` 为 `NaN`（需前收盘价）。改为索引 0 = NaN 后，`ema_wilder` 自动从索引 1
   起种、ATR/NATR 首个有效点落在索引 `period`（lookback = period），与 `talib` 对齐。
3. **`adosc`（Volume）**：原复用标准 `ema`（SMA 种子），但 TA-Lib `TA_ADOSC` 以**首个 A/D 值**为
   快/慢 EMA 种子（k = 2/(period+1)，与 Metastock 一致）。已重写。

验证：全量 `cargo test` 零失败（lib 41 / momentum 27 / stat 9 / volatility 3 / volume 3 /
overlap 14 / price_transform 4 / cycle 2 / sma 1 / doctests 18）；另用全新随机数据交叉验证
`beta` 流式移植与 `talib` 逐项一致。清理了 stale 测试头注释（momentum/volatility/cycle）与
`tools/README.md` 的"已知缺口"（13 动量函数已全部闭合），并移除未用 import（`ema_wilder` in
momentum、`ema` in volume）。构建零 warning。

结论：**A0.1 完成。** 权威黄金向量（63 个 fixture）全部与已安装 `talib` 0.7.1 1:1 通过。
