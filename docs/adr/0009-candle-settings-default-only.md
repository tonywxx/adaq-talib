# ADR 0009: 模式识别仅采用默认 candle settings

- 状态：已采纳（2026-08-09）
- 决策人：用户 + WorkBuddy（grilling 会话）

## 背景

TA-Lib 约 60 个蜡烛形态函数依赖 candle settings（实体 / 上影 / 下影的涨跌色与允许范围），原版有内建默认值。"零偏差"要求与默认一致。模式识别整体属后续里程碑（见 ADR 0002）。

## 决策

- 仅实现**默认** candle settings（与 TA-Lib 0.7.1 默认一致）。
- 不暴露 `set_candle_settings` 等配置 API。

## 权衡

- 优点：保证零偏差、缩小 API 面与验证矩阵；非默认设置无官方黄金向量可比对。
- 缺点：用户无法自定义蜡烛部件阈值（与原版可配置性不一致，但覆盖默认行为这一主路径）。
- 难以回退：若未来要加配置 API，会扩展公共 API 面，需新 ADR。

## 影响

- 模式识别模块内部固化默认 candle settings 常量；与黄金向量（默认设置生成）保持一致。
