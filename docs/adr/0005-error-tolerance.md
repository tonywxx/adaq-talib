# ADR 0005: 数值比对误差容限策略

- 状态：已采纳（2026-08-09）
- 决策人：用户 + WorkBuddy（grilling 会话）

## 背景

Rust 重实现与原版 TA-Lib 0.7.1 算法相同，但浮点运算顺序可能不同，导致末位差异。需定义与黄金向量比对的容限（见 ADR 0003）。

## 决策

采用"相对容限 + 绝对下限"的全局策略：

```
|a - b| <= REL_TOL * max(|a|, |b|) + ABS_TOL
REL_TOL = 1e-8
ABS_TOL = 1e-10
```

- 个别数值敏感指标（含 `log` / `sqrt` / 迭代求解，如 STOCH、MACD 内部 EMA、线性回归）允许在测试中按指标放宽 `REL_TOL`（如 `1e-6`）。
- NaN 处理：同位置两侧均为 `NaN` 视为通过；一侧 `NaN` 一侧有限值视为失败。

## 权衡

- 优点：兼顾大/小数量级指标，避免误判与漏判；允许按指标微调。
- 缺点：需维护少量逐指标覆盖；绝对下限的选择影响极接近 0 的值。
- 难以回退：容限是比对基准，变更会影响"是否通过"的判定。

## 影响

- `tests/` 下提供统一 `approx_eq` 断言工具，封装上述规则。
