# ADR 0002: 发布采用里程碑式，且不删减原版能力

- 状态：已采纳（2026-08-09）
- 决策人：用户 + WorkBuddy（grilling 会话）

## 背景

TA-Lib 0.7.1 约含 200 个函数（含约 60 个蜡烛形态模式识别、数学运算/变换/统计等）。一次性全量零偏差复刻工作量极大。"不删减原有指标能力"为硬性约束。

## 决策

- **0.1.0**：先覆盖高频核心指标 —— 重叠研究 + 动量 + 波动率 + 成交量（约 70 个函数）。
- 后续版本补齐：模式识别（蜡烛形态）、数学类（运算 / 变换 / 统计）、周期指标、价格变换。
- 最终达到全量覆盖；任何已发布的能力不得删减。

## 权衡

- 优点：尽早建立 crates.io 存在与反馈闭环；控制首版实现与验证风险。
- 缺点：首版不满足"全量"字面要求（但以里程碑方式兑现，不违背"不删减"承诺）。
- 难以回退：对外承诺的覆盖范围与"不删减"承诺具有持续性，影响版本路线与用户预期。

## 影响

- 测试套件与基准按里程碑分批落地。
- 文档（README / lib.rs 顶层文档）需明确当前已覆盖与待覆盖范围，避免误导。
