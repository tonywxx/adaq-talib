# ADR 0007: 不稳定期前导值约定

- 状态：已采纳（2026-08-09）
- 决策人：用户 + WorkBuddy（grilling 会话）

## 背景

TA-Lib 仅从 `outBegIdx` 起计算输出，前导若干位置不计算。需确定 Rust 侧如何表示这段空档（关联 ADR 0006 类型决策）。

## 决策

- 默认返回与输入**等长**的 `Vec<f64>`，前导不稳定期位置填充 `f64::NAN`（自对齐，调用友好）。
- 有效输出段（从 `out_beg_idx` 起）数值与原版逐项一致。
- 提供可选返回 `out_beg_idx`（前导跳过计数）的变体，供需精确对齐者使用。
- 禁止用 `0` 表示未计算（会被误读为有效值）。

## 权衡

- 优点：输出与输入等长，索引可直接对齐；无需调用方手动偏移。
- 缺点：引入 `NaN` 语义，调用方需感知 `NaN`（已在文档标注）。
- 难以回退：返回值形状是 API 契约，变更破坏 SemVer。

## 影响

- 单/多输出函数均遵循此约定；doc-comment 明确说明前导 `NaN`。
