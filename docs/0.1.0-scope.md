# 0.1.0 函数范围基线 / 0.1.0 Function Scope Baseline

> 关联 / Related: [ADR 0002](adr/0002-release-scope-milestones.md)（里程碑式发布 + 不删减承诺）。
>
> 本文档固化 0.1.0 的精确函数清单，作为实现与验收的范围基线。最终版本覆盖 TA-Lib 0.7.1
> **全部**内置函数且不删减任何原版能力；本表仅界定首版上架范围。
>
> This document pins the exact 0.1.0 function list as the scope baseline for implementation
> and acceptance. The final release covers **all** TA-Lib 0.7.1 built-ins with no deletion
> of original capabilities; this table only bounds the first publishable milestone.

## 范围口径 / Scope decision

0.1.0 覆盖 TA-Lib 四类核心指标 **加上** 价格变换与统计类，合计约 66 个（与开发基准所述"约 70"一致）：

- ✅ 重叠研究 Overlap Studies（17，全部已实现）
- ✅ 动量指标 Momentum Indicators（30，全部已实现）
- 📋 波动率指标 Volatility Indicators（3）
- 📋 成交量指标 Volume Indicators（3）
- 📋 价格变换 Price Transform（4）
- 📋 统计函数 Statistic Functions（9）
- ⏳ 模式识别 Pattern Recognition（~61）→ 后续里程碑（仅默认 candle settings，见 ADR 0009）
- ⏳ 数学算子 Math Operators（7）/ 数学变换 Math Transform（15）→ 后续里程碑

**进度 / Progress**：动量类（30/30）已全量落地；波动率/成交量/价格变换/统计（19/19）已全量落地；重叠研究已全量落地（17/17）。

合计首版 ≈ 66；模式识别 + 数学类（~83）在后续版本补齐，最终全量、不删减。

已发布能力。
