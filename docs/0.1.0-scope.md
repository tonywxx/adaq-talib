# 0.1.0 函数范围基线 / 0.1.0 Function Scope Baseline

> 关联 / Related: [ADR 0002](adr/0002-release-scope-milestones.md)（里程碑式发布 + 不删减承诺）。
>
> 本文档固化 0.1.0 的精确函数清单，作为实现与验收的范围基线。最终版本覆盖 TA-Lib 0.7.1
> **全部**内置函数且不删减任何原版能力；本表仅界定首版上架范围。
>
> This document pins the exact 0.1.0 function list as the scope baseline for implementation
> and acceptance. The final release covers **all** TA-Lib 0.7.1 built-ins with no deletion
> of original capabilities; this table only bounds the first publishable milestone.

## 范围口径 / Scope decision

0.1.0 覆盖 TA-Lib 六类核心指标（重叠研究、动量、波动率、成交量、价格变换、统计），
并以 `cycle` 模块内置 MAMA / HT_TRENDLINE（TA-Lib 亦归入 Overlap 组），合计 **65 个**
对外函数（与 `README.md` 一致；开发基准曾估"约 70"，此处以实际实现对账为准）。

> **全量对标目标（2026-08-10 实测校准）**：TA-Lib 0.7.1 共 **161** 个对外函数，
> 经本机已安装 `talib` 0.7.1（`/opt/homebrew/bin/python3`，`talib.get_functions()` 实测；
> 逐函数 `abstract.Function(name).info['group']` 取权威原生分组）确认。
> 0.1.0 已实现 **65**；剩余 **96** 在后续里程碑补齐，最终全量、不删减。
> 分类口径以 TA-Lib 原生分组为准：`MAMA` 与 `HT_TRENDLINE` 均归 **Overlap Studies**
> （代码在 `cycle` 模块，仅归类口径不同）；`AVGDEV` 归 **Price Transform**。

- ✅ 重叠研究 Overlap Studies（TA-Lib **18**，已 **17**；`ACCBANDS` 待补）
- ✅ 动量指标 Momentum Indicators（TA-Lib 31，已 **29**；`DX` / `IMI` 待补）
- ✅ 波动率指标 Volatility Indicators（3 / 3）
- ✅ 成交量指标 Volume Indicators（3 / 3）
- ✅ 价格变换 Price Transform（TA-Lib **5**，已 **4**；`AVGDEV` 待补）
- ✅ 统计函数 Statistic Functions（TA-Lib **9**，已 **9**，全量完成）
- ⏳ 周期指标 Cycle Indicators（TA-Lib **5**，已 **0**；`HT_DCPERIOD` / `HT_DCPHASE` / `HT_PHASOR` / `HT_SINE` / `HT_TRENDMODE` 全待补）
- ⏳ 模式识别 Pattern Recognition（TA-Lib 61）→ 后续里程碑（仅默认 candle settings，见 ADR 0009）
- ⏳ 数学算子 Math Operators（TA-Lib 11）→ 后续里程碑
- ⏳ 数学变换 Math Transform（TA-Lib 15）→ 后续里程碑

**进度 / Progress**：已实现合计 **65 / 161**。重叠 17/18、动量 29/31、波动率 3/3、成交量 3/3、
价格变换 4/5、统计 9/9、周期 0/5；数学算子 / 数学变换 / 模式识别均 0。

剩余 **96** = `ACCBANDS`(1) + `DX`/`IMI`(2) + `AVGDEV`(1) + 周期 5 + 数学算子 11 + 数学变换 15 + 模式识别 61。

## 后续里程碑（不删减）/ Later milestones (no deletion)

> 剩余合计 **96** 个对外函数（TA-Lib 0.7.1 全量 161 − 0.1.0 已实现 65）。
> 每一项同样遵循 P0→P1→P2 流程（先权威向量 → 测量 → 优化，见 `docs/NEXT-ACTIONS-perf.md`）。

- **本版类别内补缺（4）**：`ACCBANDS`（Overlap）、`DX` / `IMI`（Momentum）、`AVGDEV`（Price Transform）。
  这 4 个属 0.1.0 已覆盖的类别，仅个别函数未实现，优先补齐以保持类别完整。
- **周期指标 Cycle Indicators（5，全待补）**：HT_DCPERIOD / HT_DCPHASE / HT_PHASOR / HT_SINE /
  HT_TRENDMODE。TA-Lib Cycle 组共 5 个，0.1.0 均未实现；注意 `MAMA` 与 `HT_TRENDLINE`
  归 **Overlap** 组（代码组织在 `cycle` 模块）且已实现，不计入此 5 个缺口。
- **模式识别 Pattern Recognition（61）**：蜡烛形态，仅默认 candle settings（ADR 0009）。
- **数学算子 Math Operators（11）**：ADD / DIV / MAX / MIN / MULT / SUB / SUM /
  **MAXINDEX / MININDEX / MINMAX / MINMAXINDEX**。（注：旧文档记为 7，漏列 4 个 INDEX 类。）
- **数学变换 Math Transform（15）**：ACOS / ASIN / ATAN / CEIL / COS / COSH / EXP /
  FLOOR / LN / LOG10 / SIN / SINH / SQRT / TAN / TANH。

以上全部完成后，adaq-talib 即达到与 TA-Lib 0.7.1 **等量（161）全量覆盖**，且过程中不删减任何已发布能力。

## 对账记录 / Reconciliation log

> 本节记录本文档与 `src/` 实际实现的历次对账结果，便于追溯。

### 2026-08-09（A0.1 收尾后）

- **计数口径对齐**：以 `src/` 中 7 个公开模块（`overlap` / `momentum` / `volatility` /
  `volume` / `price_transform` / `stat` / `cycle`）的 `pub fn`（剔除 `*_default` 便捷变体
  与 `core` / `utils` 内部原语）逐项枚举，得到对外 TA-Lib 函数 **65** 个，与 `README.md`
  （"7 categories and 65 TA-Lib 0.7.1 indicator functions"）一致。
- **修正：动量 30 → 29**。TA-Lib 动量组名义 30 个，含 `DX`；但 `DX` 仅为内部量、无独立公共
  函数（本项目不暴露）。其余 29 个（含 `MACD` / `MACDEXT` / `MACDFIX` 三个独立入口）全部实现。
- **修正：合计 66 → 65**。原"约 66"基于动量 30；按 29 重算 17+29+3+3+4+9 = 65。
- **补遗：新增 Cycle 后续里程碑（5）**。TA-Lib 真正的 Cycle 组为 HT_DCPERIOD / HT_DCPHASE /
  HT_PHASOR / HT_SINE / HT_TRENDMODE（5 个），此前未在任何里程碑中跟踪；`MAMA` / `HT_TRENDLINE`
  已随 Overlap 组在 0.1.0 交付（仅代码置于 `cycle` 模块），不计入此 5 个缺口。
- **分类说明**：本文档按 TA-Lib 原生分组（Overlap 组含 MAMA / HT_TRENDLINE 共 17 个）统计；
  `README.md` 按项目模块布局将其单列为"Cycle (MAMA/HT_TRENDLINE)"第 7 类，两者函数总数均为 65，
  仅归类口径不同，不冲突。
- 同步修正 `src/lib.rs` 顶层文档中过时的"约 70 个函数"描述为 65。

### 2026-08-10（全量对标校准，TA-Lib 0.7.1 实测）

- **全量数字实测**：本机已安装 `talib` 0.7.1（`/opt/homebrew/bin/python3`，`import talib; talib.get_functions()`），实测 TA-Lib 0.7.1 对外函数 **161** 个（此前文档估算"≈153"偏高，已纠正）。
- **分类实测（权威口径）**：Overlap 17 / Momentum 31 / Volume 3 / Volatility 3 / Price Transform 4 / Cycle 6 / Pattern 61 / Statistic 10 / Math Operators 11 / Math Transform 15 = 161。
- **项目已实现核对（7 模块 `pub fn` 剔除 `*_default` 便捷变体，共 65）**：重叠 16/17（缺 `ACCBANDS`）、动量 29/31（缺 `DX` / `IMI`）、波动率 3/3、成交量 3/3、价格变换 4/4、统计 9/10（缺 `AVGDEV`）、周期 1/6（仅 `HT_TRENDLINE`）；数学算子/变换/模式识别均 0。合计 65 / 161。
- **纠错 1 — Math Operators 7 → 11**：TA-Lib 数学算子含 `MAXINDEX` / `MININDEX` / `MINMAX` / `MINMAXINDEX` 共 11 个，旧文档漏列 4 个 INDEX 类（已补）。
- **纠错 2 — `DX` 非内部量**：旧文档称"DX 仅为内部量、无独立公共函数"，实测 `DX` 是 TA-Lib 动量组真实公共函数（与 `IMI` 同为待补项），动量对外应为 31 而非 30/29 口径；项目现缺 `DX`/`IMI`。
- **纠错 3 — 重叠"17/17 全量"不实**：TA-Lib Overlap 第 17 个为 `ACCBANDS`，项目未实现（实为 16/17）；旧文档重叠表用自有 17 名义掩盖了这一缺口（已补 `ACCBANDS` 行并标为待补）。
- **剩余 = 96**：`ACCBANDS`(1) + `DX`/`IMI`(2) + `AVGDEV`(1) + 周期余 5 + 数学算子 11 + 数学变换 15 + 模式识别 61。最终全量目标更新为 **161**。
- 同步更新 `docs/NEXT-ACTIONS-perf.md` 的 P4 数学算子计数（7→11）及"当前已确认事实"段落（本机已装 TA-Lib C、重叠实为 16/17 等）。
