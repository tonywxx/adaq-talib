# 0.1.0 函数范围基线 / 0.1.0 Function Scope Baseline

> 关联 / Related: [ADR 0002](adr/0002-release-scope-milestones.md)（里程碑式发布 + 不删减承诺）。
>
> 本文档固化 0.1.0 的精确函数清单，作为实现与验收的范围基线。最终版本覆盖 TA-Lib 0.7.1
> **全部**内置函数且不删减任何原版能力；本表仅界定首版上架范围。
>
> This document pins the exact 0.1.0 function list as the scope baseline for implementation
> and acceptance. The final release covers **all** TA-Lib 0.7.1 built-ins with no deletion
> of original capabilities; this table only bounds the first publishable milestone.

## 范围口径 / Scope decision

0.1.0 覆盖 TA-Lib 六类核心指标（重叠研究、动量、波动率、成交量、价格变换、统计），
并以 `cycle` 模块内置 MAMA / HT_TRENDLINE（TA-Lib 亦归入 Overlap 组），合计 **65 个**
对外函数（与 `README.md` 一致；开发基准曾估"约 70"，此处以实际实现对账为准）：

- ✅ 重叠研究 Overlap Studies（17，含 MAMA / HT_TRENDLINE，全部已实现）
- ✅ 动量指标 Momentum Indicators（29，TA-Lib 动量组名义 30，DX 为内部量不对外暴露，全部已实现）
- ✅ 波动率指标 Volatility Indicators（3）
- ✅ 成交量指标 Volume Indicators（3）
- ✅ 价格变换 Price Transform（4）
- ✅ 统计函数 Statistic Functions（9）
- ⏳ 周期指标 Cycle Indicators（5，HT_DCPERIOD / HT_DCPHASE / HT_PHASOR / HT_SINE / HT_TRENDMODE）→ 后续里程碑
- ⏳ 模式识别 Pattern Recognition（~61）→ 后续里程碑（仅默认 candle settings，见 ADR 0009）
- ⏳ 数学算子 Math Operators（7）/ 数学变换 Math Transform（15）→ 后续里程碑

**进度 / Progress**：动量类（29/29，DX 不计入对外函数）已全量落地；波动率/成交量/价格变换/统计
（19/19）已全量落地；重叠研究已全量落地（17/17，含 MAMA / HT_TRENDLINE）。

合计首版 = 65 个对外函数；剩余 周期(5) + 模式识别(~61) + 数学类(22) ≈ 88 个在后续版本补齐，最终全量、不删减。

## 后续里程碑（不删减）/ Later milestones (no deletion)

  HT_TRENDMODE。注意：MAMA / HT_TRENDLINE 已在 0.1.0 随 Overlap 组交付（仅代码组织在

对外函数），且过程中不删减任何已发布能力。

## 对账记录 / Reconciliation log

> 本节记录本文档与 `src/` 实际实现的历次对账结果，便于追溯。

### 2026-08-09（A0.1 收尾后）

- **计数口径对齐**：以 `src/` 中 7 个公开模块（`overlap` / `momentum` / `volatility` /
  `volume` / `price_transform` / `stat` / `cycle`）的 `pub fn`（剔除 `*_default` 便捷变体
  与 `core` / `utils` 内部原语）逐项枚举，得到对外 TA-Lib 函数 **65** 个，与 `README.md`
  （"7 categories and 65 TA-Lib 0.7.1 indicator functions"）一致。
- **修正：动量 30 → 29**。TA-Lib 动量组名义 30 个，含 `DX`；但 `DX` 仅为内部量、无独立公共
  函数（本项目不暴露）。其余 29 个（含 `MACD` / `MACDEXT` / `MACDFIX` 三个独立入口）全部实现。
- **修正：合计 66 → 65**。原"约 66"基于动量 30；按 29 重算 17+29+3+3+4+9 = 65。
- **补遗：新增 Cycle 后续里程碑（5）**。TA-Lib 真正的 Cycle 组为 HT_DCPERIOD / HT_DCPHASE /
  HT_PHASOR / HT_SINE / HT_TRENDMODE（5 个），此前未在任何里程碑中跟踪；`MAMA` / `HT_TRENDLINE`
  已随 Overlap 组在 0.1.0 交付（仅代码置于 `cycle` 模块），不计入此 5 个缺口。
- **分类说明**：本文档按 TA-Lib 原生分组（Overlap 组含 MAMA / HT_TRENDLINE 共 17 个）统计；
  `README.md` 按项目模块布局将其单列为"Cycle (MAMA/HT_TRENDLINE)"第 7 类，两者函数总数均为 65，
  仅归类口径不同，不冲突。
- 同步修正 `src/lib.rs` 顶层文档中过时的"约 70 个函数"描述为 65。
